# Atlias native transaction experiment

Gev's PLAN-1013 items 10 and 11, grounded in RESEARCH-FIRST 0f. All options default off. Load this directory with `claude --plugin-dir ./mods/atlias-transaction`; enable options only in an isolated qualified profile. This experiment does not replace or remove native tools and makes no model calls.

The registered batch routes every operation through `$.tool.call`. Batch Read is text-only: image, PDF and page-based Read plans are rejected before preflight, and an unexpected or mixed native Read result halts with `require-native-read` without serializing its opaque payload; use native Read directly. Valid text results retain their exact text and line metadata; malformed fields reject the whole result. Read failures preserve the native textual diagnostic, denial and error marker while withholding opaque payload fields. Other tools retain their full native result. This does not change standalone native Read or add an automatic fallback. It does not invent consent, bypass a denial, roll back partial writes, or treat tool execution as a passing test. A refusal, error, unknown result or cancellation stops later operations; inspect existing effects before retrying. There is an eight-operation batch bound, with no two-inference-call task cap. Native tools remain available for longer work.

Native dispatch, ordinary permission denial, transcript storage, cancellation and token cost must be qualified on the installed Claude version before a public release. Current experimental target: Claude Code 2.1.296. This is not a proven 20x improvement.
