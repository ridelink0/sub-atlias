# Gev's Ultimate Benchmark

The machine-readable ledger is [benchmarks/ultimate.json](../benchmarks/ultimate.json). It maps35 suites to their requested evidence contracts, preserving every active benchmark family found in the reviewed plans. It does not claim unavailable adapters or experiments have run.

Inspect data availability without inference:

```powershell
node tools/ultimate.mjs inspect --corpus-root C:/Users/OWNER/atlias --out availability.json
```

Run the executable direction/accounting contracts:

```powershell
node tools/ultimate.mjs check
node test/run.mjs "Ultimate execution contracts" "every feature has a test"
```

Give a local proposer deterministic direction from a completed development report and frozen task IDs:

```powershell
node tools/ultimate.mjs direction --report development-report.json --ids frozen-task-ids.json
```

This command does not launch inference, alter source results or regrade tasks. Sealed holdout reports/traces are rejected. Each failure supplies an executable next step: grader integrity, invalid coverage, missing accounting, tool transport, context budget, failed edit or correctness. Unknown costs stay unknown. A missing suite never becomes a passed suite.

The primary goal requires two independent reductions of at least20x: total native input plus output and full native peak context. Both Codex and Claude also require matched capability noninferiority, independent receipt verification and actual causal subscription evidence. Native CLI event counters alone do not capture the full provider boundary. Acceptance retains all failures/retries and rejects output-cost regressions hidden by cheaper prompts.

Promotion requires at least250 unique main tasks, at least6 paired net wins with exact two-sided p<0.05, at least10 disjoint sealed holdout tasks, no cost-per-solve or peak regression and independent functional/adversarial receipts. Current main252 is distinct from original historic250. Adaptive search and Wilson intervals do not establish universal performance guarantees.

The ledger also covers mini-swe comparison, AST refactoring, native coding/CLI/security,40-module context,72 workflow phases, profile controls, desktop factuality, actual natural allowance crossover, Claude/web/Antigravity trials, factuality/citations/abstention, process/GPU ownership, STOP/crash/model mismatch, actual reboot/power/network loss and useful days. Added SWE-bench, Terminal-Bench, IFEval and HarnessBench require their pinned official adapters, infrastructure and graders. Mixed/model judgments remain labeled, outside the deterministic oracle.

Agents keep running after goals are reached. New work is selected from failures, remaining suite coverage and measured efficiency. They do not fabricate useful elapsed days, restart proof or20x success.
