# Gev's Atlias status website

The subject is the local harness and its execution evidence. The main job is to show which agents are working, what checks have completed and which claims still lack proof.

Tokens: paper #f3f6ff, ink #111d38, blue #2452dc, quiet #53617a, divider #c5d0e8, white #ffffff. Impact carries the large execution headline; Segoe UI carries readable status and controls. Left alignment, one asymmetric engine panel, actual table evidence and expandable suite contracts. No invented progress percentages or animated agents.

Calibration studied actual renders of Altitude101, Taobao and Apple Vision Pro. The first had a spare central mark/loading field, the second dense product information and the third an oversized product image and simple typography. This status page uses restrained type and its own actual evidence instead of unrelated product imagery or a generic stat hero. Desktop/mobile functional rendering passed before further audit iterations.

Freshness is visible; stale snapshots are labeled after15minutes. Narrow tables scroll within their container. Filters and details work by keyboard, focus remains visible, HTML evidence is inserted as text and reduced motion disables smooth scrolling. Collector output is whitelisted; private paths, prompts, hidden tasks and credentials never belong in public state.
