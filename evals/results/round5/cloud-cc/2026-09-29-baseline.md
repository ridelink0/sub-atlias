# Claude Code token study, cloud baseline, 2026-09-29

NEXTGEN-5 rows 2 and 4, CC protocol, run in the cloud container: 50 tasks x 3 arms (plain Claude Code; atlias@41f9ba6, 3.8.1 on main; atlias@d59aa98, the branch head carrying the transcript-recovery gate fix fd92b54/6c710ae), default flags. Every arm solved 50 of 50 (n=50), so no task was solved by one arm only and the solve comparison has no power on this corpus. Prompt tokens per solved task, raw: plain 137.9k, atlias@41f9ba6 146.9k, atlias@d59aa98 137.9k (n=50 each). Paired ratio against plain over the 50 tasks, raw: atlias@41f9ba6 1.07 (bootstrap 95% 0.97 to 1.18) and atlias@d59aa98 1.00 (0.94 to 1.06), both inside the noise. Billed-equivalent: 1.09 (1.04 to 1.16) and 1.06 (1.03 to 1.10), both outside it. atlias@d59aa98 against atlias@41f9ba6: 0.94 raw (0.86 to 1.00), inside the noise. Gate holds: 1 in 50 runs at 41f9ba6, 0 in 50 at the head. Cancelled hook calls: 0 of 533 at 41f9ba6 and 0 of 504 at the head, so the recovery fix had nothing to recover in this study and the main-against-head difference is not evidence about it.

## Setup

- **Claude Code:** 2.1.284 (the PC study ran 2.1.283), headless: claude -p with stream-json and hook events, model claude-sonnet-5 (the same model the PC study used, probed available here) at effort medium, permission mode bypassPermissions, --max-budget-usd 3 per run, 20-minute wall limit per run (none reached)
- **Arms:** plain; atlias@41f9ba6 (41f9ba65777f, 3.8.1, main); atlias@d59aa98 (d59aa98f8e4f, head of claude/session-limits-usage-credits-dm3isz when the study started: 41f9ba6 plus fd92b54, 6c710ae and the NEXTGEN-5 doc; its lib/ differs from main only in lib/gate.mjs and lib/track.mjs). Each atlias arm is a git archive of its SHA loaded with --plugin-dir (hooks/hooks.json, both skills and the MCP server, as a marketplace install enables them), default flags
- **Isolation:** each run: a whitelisted environment (none of the coordinating session's CLAUDE_*, CLAUDE_CODE_* or ANTHROPIC_* variables), its own --session-id, a fresh HOME (so an empty ~/.claude and ~/.atlias: no memory carries from one task to the next in either arm) and a fresh workspace under /tmp/ccstudy, outside every repository. Checked on every row from the init message (plain: no atlias plugin, skill or MCP server, and no MCP server at all; atlias: the atlias plugin and only its MCP server): 0 problems in 150 rows. A probe before the pilot asked each arm for any atlias text in its context: plain answered NONE, atlias quoted its brief
- **Tasks:** 50, picked per source with atlias's seeded sampler (lib/tiers.mjs sampleTasks, seed nextgen5-cc): 26 of 164 HumanEvalFix Python, 12 of 27 Aider polyglot Python (in git), 6 of 57 Aider refactor-benchmark, 6 of the 9 smoke-tier tasks (in git). CanItEdit could not be built: huggingface.co is blocked here and github.com/nuprl/CanItEdit ships no dataset file. HumanEvalFix Python was rebuilt from the HumanEvalPack copy on GitHub (bigcode-project/octopack e17a8f6, evaluation/create/humaneval-x/data/python/data/humanevalpack.jsonl, sha256 b1376d72...c3a7), 164 of 164 proved sound by atlias editbench; it was not byte-compared with the Hugging Face copy the PC used. refactor-benchmark at c90dfb6, 57 of 89 proved, the counts CORPORA.md gives. Each task file's sha256 is in the JSON
- **Grading:** each task's own check (lib/eval.mjs score and tamper), hidden files written only after the model stopped; the committed polyglot tasks' Windows python path is mapped to this machine's python
- **Measures:** prompt tokens raw = input + cache reads + cache writes, summed over the run's model requests from its transcript (equal to the result message's modelUsage totals on all 150 runs); billed-equivalent weights cache reads 0.1x and cache writes at their multiplier (every write here was a 1-hour write, 2x); per solved task = all tasks' tokens over the solved count, as atlias eval reports it; the paired ratio is sum(B)/sum(A) over tasks both arms solved with a 10,000-resample paired bootstrap, and beside it the geometric mean of per-task ratios with a t interval on the logs; an interval containing 1, or fewer than 6 one-way solve flips, is reported as inside the noise
- **Holds and hooks:** a hold is a Stop hook block, counted from the transcript's hook_blocking_error attachment and cross-checked against the stream (equal on every row). A 'no check ran' hold is false by atlias's rule when a command atlias's own classifier calls a check ran after the last edit, and false by any run when any interpreter command (node, python, ...) ran after it. Hook calls are the stream's hook_started/hook_response pairs; cancelled = outcome cancelled or no response
- **Concurrency:** 3 runs at a time on a 4-CPU container: the three arms of each task ran side by side, so load was the same for every arm
- **Spend:** baseline $13.41 for 150 runs (plain $4.20, atlias@41f9ba6 $4.66, atlias@d59aa98 $4.55); the whole study so far, probes and pilot included, $14.41 of the $35 cap, leaving $20.59 for the row-4 flags-on arm
- **Commands:** node tools/ccstudy/select.mjs --seed nextgen5-cc --take evals/humanevalfix/python=26,evals/polyglot=12,evals/refactor=6,evals=6 --out list.json; node tools/ccstudy/run.mjs --tasks list.json --arms plain,atlias@41f9ba6,atlias@d59aa98 --out <dir> --concurrency 3 --model claude-sonnet-5 --effort medium; node tools/ccstudy/summary.mjs --rows <dir>/rows.jsonl --meta meta.json --json out.json --md out.md

## Notes

- Ceiling: 150 of 150 runs solved. This corpus with this model measures tokens and rounds, not solves; a solve difference would need harder tasks (CanItEdit, which is blocked here, or more refactor and polyglot).
- The fixed text: on the 35 task pairs where atlias@41f9ba6 and plain used the same number of rounds, atlias read a median 1.0k more prompt tokens per round (mean 1.0k) and wrote a median 1.0k more cache tokens per task; the head arm is the same (median 1.0k per round, n=35). That is the brief, skill listing and tool text NEXTGEN-5 puts at about 1.3k per call. On HumanEvalFix (n=26) it is the whole gap: raw 1.03 (0.99 to 1.06, inside the noise), billed-equivalent 1.07 (1.05 to 1.09), because the extra text is a cache write billed at 2x.
- Output tokens: both atlias arms wrote about 20 per cent more output than plain (1.21x and 1.20x, n=50), mostly the two-pass summary lines the brief asks for; output is not part of the prompt-token ratio but is part of the cost ratio (1.11 and 1.08).
- The one hold: atlias@41f9ba6 on lint-the-file held with 'The reply says a check passed, but no check ran this turn' after the model had run node lint.mjs, which printed lint clean. atlias's classifier does not call a script named lint.mjs a check, so this hold is false by any run but not by atlias's rule, and the head's transcript recovery, which uses the same classifier, would not have caught it either. The hold cost 3 more rounds (211.2k raw against 114.7k for plain and 118.7k for the head, whose reply happened not to trip the pass-claim check). It is the largest single pair behind the main-against-head raw ratio of 0.94.
- No hook call was cancelled in 1,037 atlias hook calls (PreToolUse 368, PostToolUse 364, PostToolUseFailure 4, Stop 101, SessionStart 100, UserPromptSubmit 100, all outcome success), against 80 in 22 of 34 runs on the PC. So the recovery fix could not show an effect here, and the main-against-head comparison measures run-to-run noise between two arms whose hook code behaved identically.
- Against the PC's 1.25 (n=34): not comparable number for number. The corpus differs (polyglot and smoke tasks stand in for CanItEdit), Claude Code is one patch newer, and no hook was cancelled here. The PC's 12 clean pairs ran at 1.16 (1.06 to 1.29); the cloud's 50 pairs, all clean, run at 1.07 (0.97 to 1.18) for the same 3.8.1 code, inside the noise.
- Row 4 against this baseline: NEXTGEN-5's bar is a raw ratio against plain at or below 1.05 with an interval that excludes 1.25, and no task lost. Run it on the same 50 tasks (seed nextgen5-cc, the list below) with plain re-run in the same window; at this study's cost that is about $9 for two arms.
