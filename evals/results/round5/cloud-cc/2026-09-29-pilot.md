# Claude Code token study, cloud pilot, 2026-09-29

Pilot of NEXTGEN-5's CC protocol in the cloud container: 3 tasks x 2 arms (plain Claude Code; atlias at the branch head d59aa98), to validate isolation, grading and cost per task before sizing the baseline. It is not a result: n=3, and every comparison below is inside the noise.

## Setup

- **Claude Code:** 2.1.284, headless (`claude -p`, stream-json with hook events), model claude-sonnet-5 at effort medium, permission mode bypassPermissions
- **Arms:** plain; atlias@d59aa98 (3.8.1 plus the transcript-recovery gate fix fd92b54/6c710ae), loaded with --plugin-dir from a git archive of that SHA, default flags
- **Isolation:** each run gets a whitelisted environment (no CLAUDE_*, CLAUDE_CODE_* or ANTHROPIC_* variable of the coordinating session), its own --session-id, a fresh HOME (so a fresh ~/.claude and ~/.atlias) and a fresh workspace under /tmp/ccstudy, outside every repository. Verified by probe: the plain arm's init lists no atlias plugin, skill or MCP server and the model answered NONE when asked for any atlias text in its context; the atlias arm's init lists the atlias plugin, its two skills and its MCP server (connected), and its SessionStart brief arrived
- **Grading:** each task's own check (lib/eval.mjs score and tamper), with hidden files written only after the model stopped
- **Concurrency:** 2 runs at a time: the two arms of one task ran side by side
- **Spend:** pilot $0.66 for 6 runs; with the isolation and hold probes, $1.00 before the baseline started

## Notes

- Per-run cost: HumanEvalFix $0.065-0.072, polyglot $0.087-0.096, refactor $0.159-0.180 (n=1 each per arm).
- Token counts from the transcripts equal the result message's modelUsage totals on all 6 runs. Every cache write was a 1-hour write, billed-equivalent at 2x.
- No gate hold and no cancelled hook call in the pilot (0 of 35 atlias hook calls cancelled). A separate hold probe (atlias arm, a task that forbade running a check) produced one hold, counted once in the transcript and once in the stream; the transcript writes one hold three ways (a Stop hook feedback message, a stop_hook_summary row and a hook_blocking_error attachment) and the driver counts the attachment.
- Prompt tokens per solved task = every task's prompt tokens over the solved count, atlias eval's definition.
